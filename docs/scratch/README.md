# Scratch 가이드라인

Scratch 문서는 자유로운 아이디어 기록을 위한 공간입니다.
완성도보다 **생각을 남기는 것**을 우선합니다.

---

## 기본 원칙

- Scratch 문서는 아이디어 기록용입니다.
- 기존 파일을 대폭 수정하기보다는 **새 파일 추가를 권장**합니다.
- Scratch 문서는 **삭제하지 않습니다.**

---

## 파일 작성 규칙

- 파일명 형식:

  ```text
  {topic}-{github-id}.md
  ```

  - 예: `rule_graph-esillileu.md`
- 본인이 작성한 문서는 자유롭게 수정하고 커밋할 수 있습니다.

- 다른 사람이 작성한 Scratch 문서는 직접 수정하지 않습니다.

- 수정이나 제안이 필요할 경우, 자신의 Scratch 문서에 의견을 남깁니다.

## 아이디어 정리 흐름

- 개별 Scratch 문서는 회의를 통해 논의됩니다.

- 정리된 내용은 proposal 단계에서 하나의 문서로 통합합니다.

- proposal 문서에는 참조 링크를 통해 원본 Scratch 문서를 연결합니다.
